# ノック0: ポモドーロタイマー(React準備運動)

学習計画(`../PLAN.md`)のノック0。React の基礎を手に馴染ませ、Vercel デプロイを一度経験する。

**期間目安**: 1週間(約10h) / **完了条件**: 公開URLでタイマーが動く

## 作るもの

ポモドーロタイマー(バックエンドなしのSPA)

### MVP要件

1. 25分の作業タイマー(スタート / 一時停止 / リセット)
2. 作業タイマー終了後、5分の休憩タイマーに自動で切り替わる
3. 残り時間を `MM:SS` 形式で大きく表示する
4. 完了したポモドーロの履歴を一覧表示する(何時に完了したか)
5. 作業時間・休憩時間をフォームから変更できる

### やらないこと(スコープ外)

- 状態管理ライブラリ(Redux等)/ テスト / 通知音 / 永続化(localStorageはストレッチ扱い)

## このノックで学ぶReactの概念と対応する要件

| 概念 | どの要件で使うか |
|---|---|
| コンポーネント分割 / props | タイマー表示・操作ボタン・履歴リストを別コンポーネントにする |
| `useState` | 残り時間、動作中フラグ、作業/休憩モード、履歴 |
| `useEffect` | `setInterval` によるカウントダウン(クリーンアップ関数でクリアするのがポイント) |
| リスト描画 (`map` + `key`) | 履歴一覧 |
| フォーム(制御コンポーネント) | 作業/休憩時間の設定 |

## 進め方の目安

1. まず静的なUI(数字が固定のタイマー画面)をコンポーネント分割して作る
2. `useState` + ボタンで数字を動かせるようにする
3. `useEffect` + `setInterval` で1秒ごとのカウントダウンを実装する
4. モード切替(作業⇔休憩)と履歴を追加する
5. 設定フォームを追加する

## つまずきポイント(ヒント)

- `setInterval` のコールバック内で state を参照すると古い値を掴む → `setCount(prev => prev - 1)` の関数更新形を使う
- `useEffect` の依存配列と、return するクリーンアップ関数の役割を意識する
- 「タイマーのロジック」と「表示」を分けられると、後のノックの Component 設計につながる

## セットアップ済み

- Vite + React + TypeScript(`npm run dev` で開発サーバー起動)

## デプロイ手順(初日にやる)

1. GitHub にリポジトリを作成して push
2. [vercel.com](https://vercel.com) にGitHubアカウントで登録 → 「Add New Project」→ このリポジトリをインポート(Viteは自動検出される)
3. 以降 main への push で自動デプロイされる
